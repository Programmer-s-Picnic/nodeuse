How to learn

Each lesson has a tiny program, explanation, expected output, a practice challenge, a question, and the next lesson. Copy code and experiment with different values.

Two kinds of practice: Run in browser calculates locally and works without GoDaddy; Test on GoDaddy makes a real API call. The preview server may require login, so API connectivity is never simulated.

Lesson 13 of 20 · Strings and reverse()

13. Palindrome Check


A palindrome reads the same forwards and backwards. We normalize the text before comparing it to its reverse.


Code — copy, change and run


JavaScript / Node.js

A real program often chooses between several possibilities. The checks are evaluated from highest mark band to lowest.

Lesson 16 of 20 · Connecting a website to the server

16. Fetch Data from Node.js


fetch() makes an HTTP request. We check response.ok and parse JSON. The frontend needs the exact API hostname and permission to read cross-origin responses.


Code — copy, change and run


JavaScript / Node.js
const api = "https://11vhaiejwu.preview.c39.airoapp.ai";
async function sayHello() {
  const response = await fetch(api + "/api/hello");
  if (!response.ok) throw Error("HTTP " + response.status);
  const data = await response.json();
  console.log(data.message);
}
sayHello();


For ordinary Node.js snippets, save as lesson16.js and run node lesson16.js. Browser-only snippets are identified by their use of fetch, localStorage or page inputs.
